## What ran

Compared learned positional parameters with fixed row/column sin/cos buffers at
width 32, four heads, two encoder blocks and one predictor block. Three seeds
per arm, 2,223 updates each, batch four, unchanged mask/optimization recipe and
exactly matched actual image order. Reused three pinned learned-position models;
trained three fixed-position models locally on one CPU thread. Other initial
weights match per seed. Fixed values have a different amplitude and reduce
trainable parameter count; this is not an isolated equal-capacity comparison or
an I-JEPA reproduction.

Selected heads and k on the original 500/200 fitting/tuning rows, audited every
saved state/candidate result, then locked selections before fresh extraction.
Scored 500 new balanced validation rows excluding 1,746 declared observed rows.
No normalization/head refitting or setting selection used these fresh scores.
The official test set remains reserved.

## Fresh validation accuracy

AdamW averages three classifier seeds within each of three encoder seeds.
Ridge/kNN average encoder seeds. Pixels are a single shared representation;
duplicate saved pixel results must reproduce identically. These descriptive
averages share the same 500 examples, not independent dataset samples.

| Representation | AdamW | Ridge | Cosine kNN |
|---|---:|---:|---:|
| Trained, learned positions | 27.47% | 28.07% | 20.20% |
| Random, learned positions | 27.53% | 27.53% | 20.80% |
| Trained, fixed positions | 29.04% | 30.53% | 22.80% |
| Random, fixed positions | 28.93% | 27.40% | 21.33% |
| Pixels | 26.93% | 30.00% | 25.20% |

The predeclared trained fixed-minus-learned-position AdamW contrast is **+1.58
percentage points**. Across the nine matched head comparisons, 563 predictions
were recovered and 492 regressed; each of the 500 examples appears in all nine
comparisons, so these are not 4,500 independent examples. The ridge contrast is
+2.47 points, with 171 recoveries and 134 regressions across three paired runs.

Fixed-position trained AdamW is only **0.11 points** above its matching random
control (29.04% versus 28.93%). Trained fixed-position ridge reaches 30.53%, while
pixels reach 30.00%; pixel kNN remains higher than trained fixed kNN (25.20%
versus 22.80%). A broad learned-representation advantage is **not established**.
Do not treat the primary contrast as a confirmed best-position choice.

Encoder-seed AdamW means for trained learned positions are 27.47%, 24.87%,
30.07%; fixed positions are 28.80%, 29.60%, 28.73%. Fixed-minus-learned is negative
for one seed. Small seed counts, shared examples, historical reuse of old models
and changes in positional scale/capacity limit interpretation. Today's old-model
scores use different rows from October 15, so absolute day-over-day changes are
not model improvement.

  All reported neighbor candidates, selected settings, old scores and paired
  errors reproduce. Actual training journals match image order within each seed.
- A real cache-only retry with training, image reads, feature extraction and
  classifier fitting disabled produced a byte-identical summary.
- The first manual default-path replay exposed an evaluation default pointing
  to the previous date. Corrected that entrypoint path and added a real default
  training/evaluation/cache regression check; subsequent replay succeeded.
  This changed no model, selection, classifier or metric values.
- Full local suite before that path-only correction: 149 tests passed. All three
  position-driver checks passed after the correction. Mask demo and three-step
  synthetic training smoke also passed. CI runs the full current suite.
- Public data contains only aggregate metrics, recipes, hashes and counts.
  Actual images, features, weights, classifier vectors and per-image training
  journals stay in ignored local directories. No paid compute or APIs used.
