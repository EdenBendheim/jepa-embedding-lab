# Validation exposure history — October 19, 2026

The next confirmation experiment was blocked by the historical collector's
three-round ancestry limit. Dropping an older parent would lose observed rows.
This update retains the original source evidence and changes how it is stored
and replayed; it does not train a model or revise a reported accuracy.

## What now works

- Import verified pilot/confirmation selections into a flat dependency graph.
  Each source is retained once, with its original selection fingerprint. Replaying
  the graph reconstructs its selection protocol and derives the observed union.
- Bind local bundles to exact original source-file bytes. Rechecking a bundle
  refuses changed/missing files, including whitespace changes. File evidence is
  separate from content-level selection identity.
- Reserve balanced version-three confirmation rows from the remaining fixed
  validation partition, preserving the original fitted training rows. Later
  observations can extend history without recursively nesting the old tree.
- Retain every earlier file pin when extending a bundle. Previous snapshots and
  source files cannot be overwritten through either CLI. Invalid inputs and an
  interrupted atomic replacement preserve earlier output.
- Extract validation-only features and score saved AdamW/ridge classifiers with
  their original normalization and settings. Confirmation features remain
  ineligible for fitting/tuning. No official test rows are selected.

## Checks and limits

Ten focused synthetic exposure checks cover source replay, deduplication, six
successive later rounds, malformed/cyclic dependencies, rehashed edits, stale
file pins, idempotent/monotonic extension, per-class balance, protected inputs,
atomic failure rollback, fresh-feature fitting refusal, and unchanged saved
classifier/source bytes and RNG during scoring. The macOS temporary-path test
uses resolved paths because `/var` aliases `/private/var`.

All 160 local tests passed, along with the seeded mask demo, three-step synthetic
training smoke, and real CLI bundle replay. Training artifacts remain ignored.

The ledger is bounded to 128 unique sources and available validation capacity.
It verifies declared evidence, not producer authenticity or complete disclosure:
an experiment omitted by the caller cannot be discovered from a hash. Register
all evaluated/tuned selections, retain original files, and pin the ledger hash
before a new reservation. This does not turn repeatedly used validation data
into an official test or remove selection bias from earlier experimentation.

Latest representation results remain unchanged. Learned JEPA advantage is still
unproven, and official test evaluation remains reserved. No private data, raw
images, features, model weights, paid APIs or cloud compute were used/published.

Interview explanation: “I made later evaluation exclude every recorded earlier
validation selection, retained the original evidence, and replayed the history
before reserving new examples. That keeps repeated experiments from silently
reusing the same confirmation data.”
